## Anti-Patterns Verdict

**Does this look AI-generated? Partly — the content does not, the scaffolding does.**

**LLM assessment:** The *content* is the opposite of AI slop — specific module names, real metrics, authentic artifacts (Power BI dashboard, BRD→FSD→ERD→UC→TC hierarchy, a real defect-lifecycle kanban). That is genuine and rare. But the *section chrome* is textbook AI grammar: every one of the 11 sections carries a numbered marker (01–11) AND a tracked-label eyebrow subtitle. Two banned scaffolding patterns stacked on every section. The methodology and focus card grids are also identical icon+title+desc cards. The strong, credible substance is wearing a generic template's uniform.

- `em-dash-overuse` (warning): 28 em-dashes in body copy — an AI cadence tell.
- `overused-font` (warning): Inter. This is committed brand identity (DESIGN.md), so it is acknowledged, not a defect — but see the font-loading bug below, which is worse.

## Overall Impression

This is a content-rich, credible consultant portfolio with a real identity (slate + Implementation Blue, dark/light parity). The single biggest opportunity: **stop dressing strong evidence in AI-template chrome.** Strip the section numbers and repeated eyebrows, kill the metric repetition, and fix the broken font link — and the substance will read as distinctive instead of generic.

2. **Domain-authentic components.** The documentation hierarchy and the defect-lifecycle kanban are distinctive and exactly right for an ERP/BA audience — these are the anti-slop highlights of the page.
3. **Coherent system + nice details.** Consistent slate/blue tokens, working dark mode, and the `onerror` image fallback show care.

## Priority Issues

- **[P1] Broken web-font loading.** The `<head>` Google Fonts `<link>` (index.html:8) is several URLs concatenated with no `&`/`display` separators, so the request is malformed. Inter, JetBrains Mono, and the inline DM Mono almost certainly fail and fall back to system fonts — the entire "Engineer's Console" type system is not actually rendering as designed.
  - **Fix:** Replace with one valid request, e.g. `https://fonts.googleapis.com/css2?family=Inter:wght@300..900&family=JetBrains+Mono:wght@400;500;600&display=swap`. Drop the unused Cormorant/DM families (CSS never uses them) and replace the inline `DM Mono` captions with `JetBrains Mono`.
  - **Suggested command:** /impeccable typeset

- **[P1] AI-scaffold stack on every section.** Numbered markers 01–11 plus a tracked-uppercase eyebrow subtitle on nearly every section. This is the strongest "AI made this" tell and directly contradicts PRODUCT.md's anti-references.
  - **Fix:** Drop the running numbers; if you want sequence cues, keep them only where order is real information (the process flow, the doc hierarchy). Remove most eyebrow subtitles or fold them into the heading. Vary section cadence so the page doesn't repeat the same header recipe 11 times.
  - **Suggested command:** /impeccable quieter

- **[P2] Metric repetition / long-scroll overload.** The 86% / 97% / 82% figures appear in the Impact strip (01), again in each project card, and again in Key Achievements (08). "Impact at a glance" and "Key achievements" largely duplicate each other across an 11-section page.
  - **Fix:** Give the headline metrics one home, merge Impact + Achievements, and cut the page to the sections that earn the scroll.
  - **Suggested command:** /impeccable distill

- **[P2] Identical card grids.** Methodology (3 cards) and Functional focus (3 cards) are the banned icon/label + title + description repeated grid.
  - **Fix:** Differentiate by content shape (the doc hierarchy and kanban already prove you can), or restructure into a non-card layout.
  - **Suggested command:** /impeccable layout

- **[P2] Muted-caption contrast + em-dash cadence.** `--text-muted` (#64748b) at ~0.7rem on the tinted `--surface-2` background falls below the 4.5:1 AA floor for small text (impact captions, section subtitles). Separately, 28 em-dashes give body copy an AI rhythm.
  - **Fix:** Darken small captions toward ink (or use them on `--bg`, not tinted surfaces); replace most em-dashes with commas/colons/periods.
  - **Suggested command:** /impeccable audit (contrast) then /impeccable clarify (copy)
