The Business Context

Newton Sixth Form runs a STEM enrichment programme — 50 students per session visit Chulalongkorn University labs at ฿3,000/student/session for a 1-day programme. I manage the full financial lifecycle on XeerSoft: billing each family, tracking payment collection, investigating discrepancies, and reporting session P&L to management.

The programme spans 6 subject areas — Robotics, Biology Lab, Math Modelling, Physics Lab, Chemistry Lab, and Engineering Design — each with different student attendance, cost profile, and margin characteristics.

Functional Specification Logic

The AR posting and reporting logic I authored in the FSD and submitted to the XeerSoft development team.

// FSD-P4-01 · Per-student AR invoice generation FOR EACH student IN session.enrolled: invoice.line[1] = { 110100 Student AR · Debit · 3,000 THB · term NET30 } invoice.line[2] = { 400150 STEM Revenue · Credit · 3,000 THB · CC branch+Academic } IF post(invoice) ok → COMMIT ELSE → ROLLBACK // FSD-P4-02 · Session P&L report revenue = SUM(invoices WHERE ref ~ 'STEM%') collected = SUM(cleared WHERE ref ~ 'STEM%') cost = SUM(session_order.actual_costs) gross_profit = collected − cost margin % = gross_profit / collected × 100

Configuration Parameters

// PROGRAMME PARAMETERS Students per session : 50 pax Fee per student : THB 3,000 / session Revenue per session : THB 150,000 // GL ACCOUNT MAPPING (XeerSoft FI) 110100 Student AR → Debit (customer invoice) 400150 STEM Lab Revenue → Credit (revenue posting) Cost Centre: branch-specific (1100/1200/1300 + dept 110 Academic) // COST CATEGORIES per session Lab Fee (fixed) · Materials (variable) · Transport // AR STATUS CODES OPEN : Invoice sent, payment not received PARTIAL : Partial payment received — balance outstanding CLEARED : Full payment confirmed and reconciled DISPUTED : Amount discrepancy under investigation

AR Lifecycle Management

Each student invoice flows through four distinct status codes — OPEN → PARTIAL → CLEARED in the standard path, with DISPUTED as the exception branch when bank receipt doesn't match expected amount. I personally manage the reconciliation for any DISPUTED items, cross-checking bank statements against expected receipts.

Margin Analysis

The per-subject margin reveals where the programme generates the most economic value. Physics Lab leads at 37% margin despite lower revenue — driven by lower variable cost. Robotics generates the highest absolute profit (฿168K) due to volume. This data drives session planning and pricing decisions for upcoming intakes.
