Integration Architecture

Finance is only trustworthy if everything posts to it correctly. Two kinds of integration make that happen: the real-time module postings inside SAP (MM, SD and CO into FI) and the external interfaces to banks, the Revenue Department, POS and CRM. This map lays them out — pick an interface to see its technology, direction, trigger and error handling.
