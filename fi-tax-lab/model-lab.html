            Self-check — อธิบายได้ใน 30 วินาทีไหม

            1. เอกสาร WHT มี WIT 3 บรรทัด 5,000 / 5,000 / 5,000 base 100,000 — RPT-1 ควรออกกี่แถว base เท่าไร?

            3 แถว WHT = HSL ของแต่ละบรรทัด · base 33,333.33 / 33,333.33 / 33,333.34 (แถวสุดท้ายรับเศษ) ยอดรวมผูก 100,000.00 · ถ้ามีบรรทัด HSL 0.00 ให้ข้าม

            2. ทำไม FRM-1 ต้องใช้ BSEC แทน BP master เมื่อเอกสารมี payee?

            คนที่ถูกหักจริงคือ payee บนเอกสาร — certificate ZTAXA_F02 ใช้ BSEC-STCD3 → STCD1 → blank แล้ว ถ้าใบแนบใช้ BP master ชื่อ / Tax ID ในแบบยื่นจะไม่ตรง 50 ทวิ

            3. D3 ทางเลือก A กับ B ต่างกันตรงไหน?

            A ใช้ WT_QBSHB ของแต่ละ invoice — แถวตรง invoice แต่ยอดรวมอาจห่าง WHT ที่ post ตอนจ่ายด้วยเศษปัด · B prorate WHT ของ payment ตาม base — ยอดรวมผูกเสมอ แต่บางแถวต่างจาก invoice ไม่กี่สตางค์ · ยังไม่ตัดสิน (team lead)

            4. จ่าย invoice EUR จากบัญชี USD — ทำไม LC2 realized FX ไม่เหมือนจ่ายด้วย EUR?

            เอกสาร USD → LC2 = LC3 = doc amount (กฎ 1) ค่า LC2 ของบรรทัด bank จึงเท่ากับยอด USD ที่จ่ายจริง ส่วนเอกสาร EUR ใช้ cross rate ZTH(EUR:THB) ÷ ZTH(USD:THB) · บรรทัด vendor ใช้ historical ทั้งสองแบบ

            5. control อะไรพิสูจน์ว่า RI filter ไม่ทำเอกสารหาย?

            รันทีละ RI แล้วรวมทุก bucket ต้องเท่ากับรันแบบไม่กรอง — Σ(buckets) = unfiltered total · ถ้าน้อยกว่า = เอกสาร mixed-RI หาย ถ้ามากกว่า = นับซ้ำ
