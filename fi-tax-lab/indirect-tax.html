Tax code chain STD

Company code→T001-LAND1→Tax procedure TAXTH→Tax code (FTXP)→Condition + rate→Account key→GL (OB40 / T030K)
  • Tax codes เป็นของ ประเทศ ไม่ใช่ของ company code — CoCd ที่ LAND1 เดียวกันใช้ชุด code เดียวกัน
  • Tax procedure: QAS T005-KALSM ของ TH = TAXTH (ตรงกับ BPE) · MY = ZTXP_MY · Oman = ZTXP_OM SYS — training deck เคยเขียน ZTXP_TH → ยึดค่าใน T005 (C14)
  • Account keys: VST input (เคลมได้) · NVV non-deductible (บวกเข้าบรรทัด expense / GR-IR จึงไม่มีบรรทัดภาษีแยก) · MWS output · ESA/ESE คู่ acquisition / reverse charge
  • Tax code มาจาก: PO item (MIRO) · user กรอก (FB60/FB70) · SD condition MWST (VK11) ตาม customer + material tax classification
  • BSET: MWSKZ, KTOSL, FWBAS/FWSTE (doc ccy), HWBAS/HWSTE (LC1), H2BAS/H2STE (LC2), H3BAS/H3STE (LC3), KBETR (rate)
  • Standard VAT return report: RFUMSV00 (S_ALR_87012357) — line items, totals ต่อ code, balance ต่อ CoCd, optional “tax payable” posting · TAX-RPT-2 คือ Z-copy ของมัน

Input vs Output VAT

ซื้อ · Purchase · KTOSL VST

Input VAT = Dr

ภาษีซื้อ — สินทรัพย์รอเครดิตกับภาษีขาย ไม่รวมเป็นต้นทุน (เว้นแต่ code แบบ unclaimable / NVV)

ขาย · Sales · KTOSL MWS

Output VAT = Cr

ภาษีขาย — หนี้สินที่ต้องนำส่งในงวด

ภ.พ.30: Output VAT − Input VAT = ภาษีที่ต้องชำระ (หรือขอคืน / ยกไป) · ยอดในแบบต้อง = ยอดใน GL เสมอ · ไทย 7% · FC แปลงเป็น THB ด้วย BOT rate ของวันทำการก่อนหน้า (T-1) STD

    Self-check

    1. GR (MIGO 101) post ภาษีไหม?

    ดูเฉลย
    ไม่ — ภาษีเกิดตอน invoice (MIRO / billing / FB60 / FB70) เท่านั้น

    2. ทำไม code แบบ NVV ไม่มีบรรทัดภาษีแยก?

    ดูเฉลย
    NVV บวกภาษีเข้าไปในบรรทัด expense / GR-IR — expected ไม่ใช่ defect

    3. ZTAXA_R02 กับ ZTAXA_R03 ต่างกันอย่างไร?

    ดูเฉลย
    030 = ENH-3 สร้าง VAT36 liability หลังปิดงวด (SA) · 032 = ENH-2 ปรับ WHT FX (SW)

    4. Tax code “D1” ในไทยหมายถึงอะไร และถูกโอนเมื่อไร?

    ดูเฉลย
    Deferred input VAT (บริการ) อัตรา 7% · โอนเป็น input ปกติตอนจ่ายเงินโดย TAX-ENH-8 (doc ST)

    5. บัญชี VAT กำหนดที่ OB40 หรือ OBYC?

    ดูเฉลย
    OB40 ผ่าน tax code / account key · OBYC เป็นของ MM automatic postings (BSX, WRX …)
