Source: knowledge base tax-fundamentals (STD) · 10-client-fi-design §8 · BPE KDS · course TAX-301 (4-Jun-2026) · 20-role-wricef-owner (shared engine)

ภาษีใน SAP มีสองเครื่องยนต์: tax code (VAT คิดตอน invoice → BSET) และ Extended Withholding Tax (หัก ณ ที่จ่าย ส่วนใหญ่คิดตอนจ่าย → WITH_ITEM) · หน้านี้คือเครื่องยนต์ตัวที่สอง — ตั้งค่าอะไร, ไหลยังไง, ออกแบบ/ไฟล์จากไหน และทำไมต้องมีโปรแกรมปรับ FX (ENH-2)
Engine Types & codes Gross-up TH flow Output groups e-WHT Posting chain FX adjustment Self-check
Key takeaways
  • WHT type = เมื่อไร/อย่างไร (invoice หรือ payment) · WHT code = อัตรา + ประเภทเงินได้ · recipient type = จ่ายให้ใคร → แบบไหน
  • บรรทัด WHT ใน ACDOCA มี KTOSL = WIT · type ที่หักตอนจ่ายจะมี amount 0 ที่ invoice
  • แบบ / ใบแนบ / ไฟล์ WHT ไทยออกจาก โปรแกรมเดียว (ZTAXB_R01 บน Generic WHT Reporting) แยกด้วย output group — ไม่ใช่ DRC
  • FX adjustment TAX-ENH-2 (ZTAXA_R03) batch ปรับ WHT ให้ตรงวันจ่าย · doc SW · GL A212X021
  • ยอดต้องผูกกัน: 50 ทวิ = ใบแนบ = text file = RPT-7 = WHT payable GL credit = ยอดนำส่ง

    e-WHT & 50 ทวิ

    • e-WHT: ธนาคาร (HSBC / BOFA) หักและนำส่ง RD ภายใน 4 วัน · FX ใช้ BOT rate T-2 · ธนาคารเป็นผู้ออกหลักฐาน → ธุรกรรม e-WHT ไม่ generate 50 ทวิ ผ่าน DRC · implement ตาม bank readiness BP
    • Paper WHT กับ e-WHT ใช้ บัญชี WHT แยกกัน (A212X021 / A212X022) — กระทบยอด/นำส่งให้ถูกสาย (course TAX-301)
    • TO-BE (คอร์ส TAX-405): 50 ทวิ, แบบ PND54, ใบแนบ, ไฟล์ RD / SWC แยกตาม PC & RI จาก ZTAXB_R01 — ไม่ใช่ DRC (TAX-FRM-5 ถูกยกเลิก แม้ Blueprint ยังเขียนว่า DRC) · WHT / e-WHT ใน payment file ผ่าน DMEE
    • อัตรา e-WHT 1% (Ministerial Reg. 389) หมดอายุ 31-Dec-2025 — ยืนยันอัตราปัจจุบัน (G6) TBC

    • TH paper = T-1 · TH e-WHT = T-2 · MY = posting date (T)

    • เสาร์–อาทิตย์ไม่มี rate → ใช้ rate ล่าสุด (จ่ายจันทร์ → rate ศุกร์)
