Key takeaways
  • ทุกบรรทัด FI + CO + AA อยู่ใน ACDOCA · ภาษีทางอ้อมเขียน BSET · WHT เขียน WITH_ITEM — รายงานภาษีทุกตัวแค่อ่านสองตารางนี้มาจัดรูป

JVA dimensions บนทุกบรรทัด BP JVA

  • Controlling area เดียว · profit center = แหล่งน้ำมัน/ก๊าซ (field) · PC ไม่มีข้อมูล JV
  • ทุกบรรทัด P&L / BS มี venture (JV) + equity group + recovery indicator (RI) + cost object · บรรทัดภาษีได้ป้าย JV ผ่าน document splitting INFER — verify in SIT
  • RI: BR, BN (operated) · NR (non-op) · NN · CR, CN (cutback ของ BR/BN) · CP (corporate) · ZA (TH, FX spot ผ่าน TRM) · RI accrual เฉพาะ MY B1/B2/N1/N2/C1/C2 · master ต่อ CoCd = T8JJ
  • Cash call: ไม่ใช้ standard SAP cash call → Excel upload JVA-ENH-1 + workflow JVA-WFL-1 · doc types JD / JK · ไม่มีบรรทัดภาษี → Oman ต้องได้ tax code I0 (substitution, user exit EJVA017) สำหรับ TAX-RPT-2
  • Cutback (GJCBA) map บัญชี A → B · บัญชีภาษีถูก cutback ไหม และเอกสาร cutback เข้า T1 ไหม — เปิด (G7)
  • Mirror cost objects: cost center prefix N (non-op) / T (net operated) · PC prefix ที่เห็น: C (corporate), N (non-op), O (operated), B… ความหมาย TBC กับทีม CO
