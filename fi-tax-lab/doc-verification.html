กฎ 1 · Document currency ตัดสินว่าอะไร “ไม่ต้องแปลง”

THB doc → LC1 = doc amount · USD doc → LC2 = LC3 = doc amount · FC อื่น → แปลงทั้งสามชั้น โดย LC2/LC3 เป็น cross rate ผ่าน THB = DC × ZTH(FC:THB) ÷ ZTH(USD:THB)
