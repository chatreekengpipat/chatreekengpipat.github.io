Key Takeaways
  • Backbone มาตรฐาน 1 ชุดใช้ทุกภาษี: คัดกรอง (VIM) → รัน report (S/4) → recon → เตรียมแบบ (DRC) → review/approve (DAS) → ยื่น (portal) → จ่าย (AP) → archive (xECM)
  • ระบบหลักที่ต่อกัน: S/4HANA · OpenText VIM · SAP DRC · SAC · Online Tax Portal · Bank (HSBC/BOFA) · xECM · Business Network
  • Client = ปิโตรเลียม → เสีย CIT + PITA · ใช้ Segment = tax regime (CIT/PITA/PSC/MTJDA) เป็นตัวขับการแยกภาษี + FX
  • Currency: LC1=COO · LC2=USD (group) · LC3=USDTH (tax, เฉพาะ 0L/T1 บริษัทไทย)
  • DRC ใช้กับ P.P.30 text file / e-Tax / MY e-invoice (DRC statutory forms ไม่ใช้ — CR-A dropped, Jul-2026) — แต่แบบ / ใบแนบ / ไฟล์ WHT ไทยออกจาก ZTAXB_R01 (TAX-FRM-5 ถูกยกเลิก แม้ BPE ยังเขียน DRC)

Self-check

1. ระบบไหนสร้าง “แบบยื่น statutory” (PP30/PND) และระบบไหนจัดเก็บเอกสาร?

ดูเฉลย
P.P.30 text file / e-Tax = SAP DRC (ไม่ใช้ DRC statutory forms) · แบบ/ใบแนบ/ไฟล์ WHT ไทย = ZTAXB_R01 output groups (ไม่ใช่ DRC) · จัดเก็บ = xECM / Document Center

2. e-WHT จ่ายผ่านใคร ภายในกี่วัน และมีข้อห้ามอะไร?

ดูเฉลย
ธนาคาร HSBC / BOFA จ่าย RD ภายใน 4 วัน · ห้ามออก 50BIS ผ่าน DRC

3. LC3 คือสกุลอะไร ใช้กับ ledger/บริษัทใด?

ดูเฉลย
USDTH (tax currency, PITA) · เฉพาะ ledger 0L & T1 และ บริษัทไทย

4. Segment ใน Client ใช้แทนอะไร และ derive จากไหน?

ดูเฉลย
แทน tax regime (CIT/PITA/PSC/MTJDA) · derive ด้วย substitution TAX-ENH-4: ZTAXB_T04 (G/L) → ZTAXB_T05 (CC + IO) → segment ของ profit center

5. หลักแรกของ WHT Code D และ G หมายถึงอะไร?

ดูเฉลย
D = DTA rate · G = Gross Up – Standard rate
