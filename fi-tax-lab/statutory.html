งงว่า “ภาษีตัวนี้ต้องยื่น PND อะไร”? กุญแจคือ 2 คำถาม — ① จ่ายให้ ใคร (บุคคล / นิติบุคคลในไทย / ต่างประเทศ) ② เป็น เงินได้ประเภทไหน (มาตรา 40) แล้วแบบยื่นจะตามมาเอง หน้านี้ไล่ทุกแบบพร้อม ตัวอย่างจริง (case) และจุดเชื่อมใน SAP

Key Takeaways
  • ผู้รับเงินเป็นใคร คือตัวตัดสินหลัก: บุคคล → PND1/2/3 · นิติบุคคลในไทย → PND53 · ต่างประเทศ → PND54
  • PND54 (จ่ายออกนอกประเทศ) มักมาคู่กับ VAT36 → PP36 (reverse-charge VAT)
  • VAT รายเดือน = PP30 · นำส่ง VAT แทน = PP36 · หนังสือรับรองหัก = 50BIS (50 ทวิ)
  • WHT ทุกแบบ (PND1/2/3/53/54) ยื่น ภายในวันที่ 7 ของเดือนถัดไป · PP30 ภายในวันที่ 15 (e-filing +8 วัน)
  • Direct tax: CIT = PND50 (ปี) / PND51 (ครึ่งปี) · Client มี PITA (ปิโตรเลียม) เพิ่ม

WHT — แบบ ภ.ง.ด. (case ต่อแบบ)

แต่ละแบบพร้อมตัวอย่างในบริบท Client + จุดเชื่อมในระบบ

ภ.ง.ด.1รายเดือน
WHT เงินได้จ้างแรงงาน (PND1)
ผู้รับพนักงาน / บุคคล เงินได้40(1) เงินเดือน · 40(2) ค่าจ้าง/นายหน้า อัตราก้าวหน้า (เงินเดือน) verify ยื่นภายในวันที่ 7 · สรุปปี = 1ก
📌 CaseClient จ่าย เงินเดือนพนักงาน → หักตามอัตราก้าวหน้า → ยื่น ภ.ง.ด.1 รายเดือน แล้วสรุปทั้งปีด้วย ภ.ง.ด.1ก
ภ.ง.ด.2รายเดือน
WHT ดอกเบี้ย / เงินปันผล / royalty บุคคล (PND2)
ผู้รับบุคคลธรรมดา เงินได้40(3) royalty · 40(4) ดอกเบี้ย / เงินปันผล อัตราเช่น ดอกเบี้ย 15% · ปันผล 10% verify ยื่นภายในวันที่ 7 · สรุปปี = 2ก
📌 Caseจ่าย ดอกเบี้ย/เงินปันผล ให้ผู้ถือหุ้น/ผู้ให้กู้ที่เป็นบุคคล → หัก → ยื่น ภ.ง.ด.2 (ปันผลสรุปปีด้วย 2ก)
ภ.ง.ด.3รายเดือน
WHT จ่ายบุคคลธรรมดา (PND3)
ผู้รับบุคคลธรรมดา เงินได้40(5)–(8) เช่า · วิชาชีพ · รับเหมา · บริการ อัตราเช่น บริการ 3% · เช่า 5% verify ยื่นภายในวันที่ 7
📌 Caseจ้าง ที่ปรึกษาบุคคล (freelance) ฿50,000 → หัก 3% = ฿1,500 → ออก 50BIS → ยื่น ภ.ง.ด.3
ภ.ง.ด.53รายเดือน
WHT จ่ายนิติบุคคลในไทย (PND53)

📌 Caseจ่าย บริษัทไทย ค่าบริการ 100,000 → หัก 3% = 3,000 (WIT line ตอนจ่าย) → ยื่น ภ.ง.ด.53 · WHT type 4A–4F + recipient type 53 ต้องครบ ไม่งั้นบรรทัดหลุดจากใบแนบ TAX-FRM-1 / text file TAX-ENH-1
ภ.ง.ด.54รายเดือน
WHT/นำส่ง จ่ายไปต่างประเทศ (PND54)

ระบบรู้ได้ยังไงว่าต้องยื่นแบบไหน — 3 ชั้นที่ยืนยันจาก FD

เลิกเดา · ค่าจริงจาก FD ของ TAX-ENH-1 และ TAX-FRM-1 · ทุกค่าใน WITH_ITEM

ตรรกะ 3 ชั้น (จำลำดับนี้ = ตอบได้ทุกเคส)
  • ชั้น 0 · ตัวชี้ว่าเป็นบรรทัด WHT — ACDOCA-KTOSL = 'WIT'
  • ชั้น 1 · WHT Type (WITH_ITEM-WITHT) — บอกว่าเป็น “ภาษีอะไร”
  • ชั้น 2 · Recipient Type (WITH_ITEM-QSREC) — ยืนยัน “ยื่นแบบไหน”
  • ชั้น 3 · WHT Code (WITH_ITEM-WT_WITHCD) — ระบุ “ประเภทเงินได้” (ช่อง 5 ของแบบ)

VAT — แบบ ภ.พ.

ภ.พ.30รายเดือน
แบบแสดงรายการ VAT (PP30)
คือOutput VAT − Input VAT ของงวด ยื่นภายในวันที่ 15 (e-filing +8 วัน) ในระบบRPT-6 VAT report + net VAT clearing (doc SO) → P.P.30 text file ผ่าน DRC (DRC statutory forms ไม่ใช้ — CR-A dropped) · recon TAX-RPT-11 · ยอด = G/L
📌 Caseขายก๊าซ/บริการในไทย → เก็บ output VAT 7% · ซื้อของ/บริการ → input VAT · สุทธินำส่งด้วย ภ.พ.30
ภ.พ.36เมื่อจ่าย
นำส่ง VAT แทน — reverse charge (PP36)
คือจ่ายค่าบริการต่างประเทศ → ผู้จ่ายในไทยนำส่ง VAT แทน คู่กับVAT36 · จับคู่ PND54 ยื่นภายในวันที่ 7 ของเดือนถัดไป ในระบบZTAXA_R02 สร้าง VAT36 liability (TAX-ENH-3, doc SA) · แบบ P.P.36 = TAX-FRM-6

หนังสือรับรองหัก ณ ที่จ่าย (50BIS)

50 ทวิ (50BIS) = หนังสือรับรองการหักภาษี ณ ที่จ่าย ตามมาตรา 50 ทวิ ออกให้ ผู้ถูกหัก ทุกครั้งที่หัก (ทุกแบบ PND) · ในระบบพิมพ์จาก FRM-3 output group AP1 บน ZTAXB_R01 (แยกตาม PC & RI ได้)

กฎ e-WHT: ธุรกรรม e-WHT ต้อง ไม่ generate 50BIS ผ่าน DRC (ธนาคารเป็นผู้ออกหลักฐาน) · paper กับ e-WHT ใช้บัญชี WHT แยกกัน

Self-check

1. Client จ้าง “บริษัทรับเหมาไทย” ทำงานบริการ — ยื่นแบบอะไร?

ดูเฉลย
ภ.ง.ด.53 (ผู้รับเป็นนิติบุคคลในไทย)

2. จ่ายค่าบริการให้ “บริษัทต่างประเทศ (ไม่มี PE)” — ต้องยื่นอะไรบ้าง?

ดูเฉลย
ภ.ง.ด.54 (WHT) และ ภ.พ.36 (VAT36 นำส่งแทน)

3. จ่ายค่าที่ปรึกษาให้ “บุคคลธรรมดา freelance” — แบบไหน?

ดูเฉลย
ภ.ง.ด.3 (บุคคลธรรมดา เงินได้ 40(5)–(8))

4. VAT รายเดือน กับ นำส่ง VAT แทน ใช้แบบอะไร และกำหนดวันไหน?

ดูเฉลย
ภ.พ.30 (วันที่ 15) · ภ.พ.36 (วันที่ 7)
