Execution sequence

  1. Prepare config & access — CoCd, tax/WHT codes, output group R03, PC/RI authorization, rate entries, variants, layouts
  2. Capture immutable baselines — selection screen ก่อน Execute · FB03 header · WITH_ITEM · BSET/BSEG · ACDOCA 0L WIT lines · BSAK/BSIK · TCURR รอบ ๆ วันที่
  3. Clear upstream blockers — TKT-02 (GL) · GL-ENH-1 + ENH-2 dual-write · ข้อมูล ENH-3 · ZCAX_P01 / BAdI สำหรับ 5G
  4. RPT-1 read-only core — TC-002/003/004/005/008/009
  5. Shared R03 siblings — variant เดียวกันผ่าน FRM-1 และ ENH-1 แล้วเทียบ count / base / WHT ต่อ PC/RI
  6. RPT-2 — ZVAR_CC (cash call) แล้ว ZVAR_FULL (standard / split) · balances · RTF
  7. FRM-2 หลังผ่าน scope gate เท่านั้น
  8. Regression & closure — ทุกครั้งที่ wrapper / WITH_ITEM เปลี่ยน ให้ retest sibling · เก็บ sign-off
Write-object rule: ENH-2 และ ENH-3 เขียนข้อมูล — เก็บ baseline ก่อนเสมอ และห้ามติ๊ก Update run ลอย ๆ · Hard stop: ห้ามเรียก output ผิดว่าเป็น report defect จนกว่าจะ trace เอกสาร + three-layer check + row-disappearance ladder ครบ

Cross-object tie-out

  • RPT-1 WT total = ใบแนบ FRM-1 WHT total (scope R03 / PC / RI เดียวกัน)
  • ENH-1 control totals = WITH_ITEM ต่อ WITHT / QSREC · จำนวนบรรทัดเปลี่ยนต้องอธิบายได้ด้วยกฎ split / filter
  • RPT-2 = BSET (standard path) และ BSEG-DMBE2 / ACDOCA-KSL (cash-call path)
  • FRM-2 fields = คู่ field ของ WITH_ITEM ตามสกุลที่เลือก + vendor master
  • ภาพรวม WHT: 50 Tawi = ใบแนบ = text file = RPT-7 = WHT payable GL credit = ยอดนำส่ง
