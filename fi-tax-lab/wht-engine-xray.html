สิ่งที่โค้ดสอน (เอาไปใช้ตอนเทส)

RPT-7 ≠ RPT-1

AP1 / AR1 ข้าม check_witht และ country BAdI alldata_modify — ถ้า RPT-7 กับ RPT-1 ให้แถวไม่เท่ากัน ให้ดูตรงนี้ก่อนสงสัย data

sy-tcode ใช้ไม่ได้

เงื่อนไข sy-tcode <> 'ZTAXB_R01' ถูก comment ทิ้ง · ตัวจริงที่ใช้คือ GV_OUT_GRP และ memory ID ZTAXA_R01_OUTPUTGROUP — ตรงกับบทเรียนว่า background job ไม่มี T-code ให้พึ่ง

รายงานว่าง ≠ bug

ถ้าทุกแถวถูกกรองหมด จะขึ้น 7Q 702 “No items have been selected” · ไล่ row-disappearance ladder: select → BAdI → check_witht → PC/RI → output

ไฟล์ vs ฟอร์ม

ENH-1 / ENH-6 / ENH-5 วิ่ง standard dispatcher ส่วน RPT-1 / FRM-1 / AP2 / AP3 วิ่ง custom dispatcher — แก้ฝั่งหนึ่งไม่ทำให้อีกฝั่งเปลี่ยน แต่ แก้ตอน select / filter กระทบทั้งคู่
