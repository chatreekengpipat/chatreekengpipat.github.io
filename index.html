How I work

i.
SDLC Foundation
Waterfall + Iterative

Projects on XeerSoft followed a hybrid model: Waterfall for upfront discovery and FSD authoring, then iterative UAT cycles with weekly Dev builds. Each project averaged 5 build cycles before Go-Live.

ii.
Agile Awareness
Sprint-like Cadence

Dev team delivered weekly builds. I tested 1–3 days per build (depending on complexity), met 2× per week for review and defect triage, functionally identical to Agile Sprint cadence with shorter cycles.

iii.
Documentation First
FSD → ERD → UAT

Every project starts with a written FSD before code. ERDs map data relationships. UAT test cases trace back to FSD requirements. No code is built without a signed-off spec.
